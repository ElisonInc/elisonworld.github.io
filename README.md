# Elison World — Legacy Prototype

> **Historical repository.** The current Elison World project lives at [`emorban/elison-world-website`](https://github.com/emorban/elison-world-website) and is deployed at [elisonworld.com](https://elisonworld.com).

This repository contains an earlier static prototype of the Elison World concept. It explored a cinematic artist website connecting music, technology, and the broader ELISON INC product ecosystem.

## Why This Repo Still Exists

The project is kept public as part of the design and product history behind Elison World. It shows an earlier implementation before the experience moved to the newer Vite + React codebase.

## Original Stack

- HTML5
- CSS3
- Vanilla JavaScript
- GSAP + ScrollTrigger
- GitHub Pages

## Current Project

For the active version, see:

- **Repository:** https://github.com/emorban/elison-world-website
- **Live site:** https://elisonworld.com

## Portfolio Context

Elison World is an experimental artist website concept built with Elison as the first case study, exploring how music, visuals, story, projects, and digital identity can live together in one immersive web experience.
